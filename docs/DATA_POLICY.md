# Data policy

This repository is code-only.

Hospital CT, DICOM, NIfTI volumes, reference-standard contours, and any derived
dense feature volumes computed on the private multicenter cohort are excluded
by `.gitignore` and are not part of any release tag.

Users must supply their own images and organ masks. Public experiments in the
paper that can be reproduced without private data use AMOS22 and WORD.
